# نَواة | NAWA Engineering Office

واجهة عربية متعددة الصفحات لمساحة عمل مكتب هندسي: المشاريع، التغييرات، المهام، الملفات والإصدارات، الاعتمادات، الفريق، بوابة العميل، التقارير، ومركز تحليل تجريبي. الهوية مستلهمة من درجات أخضر النخيل والرمل والذهبي السعودي مع واجهة RTL متجاوبة.

## تشغيل

تتكون الصفحات من ملفات HTML مستقلة وتستخدم JavaScript modules؛ شغّل خادم ملفات ثابتة من هذا المجلد:

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000/` ليدخلك مباشرة إلى واجهة النسخة الأساسية (`mvp.html`). الواجهة مركزة ومصنفة حسب الدور، أما التجارب الإضافية فلها قسم منفصل. بقية الأقسام متاحة مباشرة كصفحات: `projects.html`, `workspace.html`, `changes.html`, `thread.html`, `tasks.html`, `files.html`, `approvals.html`, `team.html`, `client.html`, `ai.html`, `reports.html`, و`settings.html`.

## بنية المشروع

- `assets/css/tokens.css`: ألوان وهوية التصميم.
- `assets/css/app.css`: التخطيط والمكونات والتجاوب.
- `assets/js/store.js`: بيانات العرض المحلية ونموذج الحالة.
- `assets/js/shell.js`: التنقل المشترك والبحث والقوائم المصنفة حسب الدور.
- `assets/js/app.js`: صفحات وسير العمل والتفاعلات ولوحات البداية المخصصة لكل دور.
- ملف HTML مستقل لكل قسم.

## النشر

يتضمن المستودع سير عمل GitHub Pages. بعد تفعيل Pages في إعدادات المستودع واختيار GitHub Actions كمصدر، يُنشر الموقع عند تحديث الفرع `main`.

## تجربة المعاينة

تعرض لوحة البداية لكل دور المعلومات التي تخصه. الأقسام الأساسية مفصولة عن مختبر الذكاء التجريبي. يمكن إضافة مشروع ومهمة وطلب تغيير وعضو وتسجيل مستند وصنع قرار، وتُحفظ العناصر في `localStorage` على المتصفح الحالي. البحث العام وروابط صفحات المشروع والمرشحات والخريطة الهندسية تفاعلية. إعادة ضبط البيانات متاحة من الإعدادات.

مركز الذكاء موسوم بوضوح كمحاكاة محلية وغير متصل بمزود AI. تحليل الأثر تجريبي ويتطلب مراجعة مهندس. رفع الملفات، دعوات المستخدمين، اعتماد العميل، إرسال التنبيهات، وتسجيل الدخول غير مفعلة. لا تستخدم بيانات مشاريع سرية في المعاينة.

## الربط القادم

بعد اعتماد الواجهات، يضاف تكامل AI عبر API خادمي آمن مع صلاحيات حسب الدور، مصادر موثقة، وسجل تدقيق ومراجعة بشرية قبل إنشاء أو اعتماد سجلات هندسية. لا تحفظ مفاتيح مزود AI في الواجهة أو المستودع.
