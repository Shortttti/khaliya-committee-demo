# خلية | KHALIYA — نسخة العرض للجنة

نسخة مستقلة من واجهات خلية، مهيأة لعرض تدفق العمل بين المكتب ومدير المشروع والمهندس والعميل والاستشاري.

## حسابات العرض الجاهزة

من صفحة تسجيل الدخول، اختر «الدخول السريع للجنة». الحسابات الخمسة تدخل مباشرة إلى المكتب التجريبي ومشاريعه وبياناته المشتركة؛ لا تحتاج كلمة مرور.

## ما يعمل في نسخة العرض

- صفحات المشاريع والمهام والملفات والتغييرات والقرارات والاجتماعات والجدول والكميات والتقارير والفريق والعميل والاستشارات.
- إجراءات الإضافة والتحديث والاعتماد والتنسيق تحفظ محليًا في المتصفح، وتظهر عند تبديل الدور في المتصفح نفسه.
- تهيئة حسابات جديدة محليًا مع رمز دعوة `KHL-2026`.
- لا يوجد اتصال Firestore ولا حفظ سحابي لبيانات العرض.

## الذكاء الاصطناعي

تستخدم وحدات AI عامل KHALIYA الحالي `khaliyah-engineering-office.short-story-im.workers.dev`. من شاشة الدخول، أدخل بريد وكلمة مرور حساب KHALIYA الفعلي لتكوين جلسة Firebase Authentication؛ لا يُنشأ سجل Firestore من نسخة العرض. طلبات AI ترسل سياق المشروع التجريبي يدويًا مع `useKnowledge:false`، فلا تسترجع ملفات المشروع أو بياناته. العامل الحالي يتحقق من ملف هوية المستخدم في الخلفية؛ بقية بيانات العرض لا تُرسل إلى Firestore.

## نشر Pages

المستودع يحتفظ بـ workflow النشر إلى GitHub Pages. بعد تفعيل Pages للمستودع، كل تحديث إلى `main` ينشر النسخة. بيانات العرض محفوظة على جهاز كل زائر ويمكن إعادتها بمسح تخزين الموقع.

> البيانات والأسماء والمشاريع الظاهرة تجريبية. الحسابات التجريبية لا تمثل مستخدمين حقيقيين.
