# نَواة | NAWA

مساحة عمل سحابية للمكاتب الهندسية تربط المشاريع والملفات والفريق والقرارات والتغييرات الهندسية في تجربة عربية من اليمين إلى اليسار.

## تجربة الموقع

- الصفحة الرئيسية تعرّف المنصة وتشرح الخيط الهندسي الرقمي.
- تسجيل الحساب يوجّه المستخدم حسب نوعه: مكتب هندسي، مهندس أو عميل.
- التهيئة الأولية تعرض مسار إنشاء المكتب أو الانضمام بدعوة.
- مساحة العمل تعرض تجربة مختلفة لمديرة المكتب ومدير المشروع والمهندس والعميل.
- أقسام المشاريع تشمل الملفات والإصدارات، المهام، التغييرات، القرارات، الاجتماعات، الاعتمادات، الجدول، الكميات، سجل المشروع، الخيط الهندسي، التقارير ومساعد نَواة.

## تشغيل محلي

يمكن فتح `index.html` مباشرة أو تشغيل خادم ملفات ثابت داخل هذا المجلد. صفحات المنصة تستخدم وحدات JavaScript، لذا يفضّل خادم محلي عند الاختبار.

## حالة البيانات والخدمات

الموقع المنشور تجربة واجهات تفاعلية ببيانات توضيحية محفوظة محليًا في المتصفح. تسجيل الحسابات، صلاحيات الوصول الحقيقية، دعوات الفريق، رفع الملفات وتخزينها، والمساعد الذكي تتطلب خدمات خلفية. لم يوضع أي مفتاح API في ملفات المتصفح. لا تستخدمي بيانات مشاريع سرية في النسخة العامة.

الذكاء الاصطناعي مصمم كطبقة مساعدة مرتبطة بسياق المشروع ومراجعة بشرية، وليس كبديل عن القرار الهندسي أو نظام الصلاحيات.
