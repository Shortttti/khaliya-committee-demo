# نَواة | NAWA

واجهة عربية متجاوبة للمكتب الهندسي السحابي الذكي، تركّز على ترابط المشروع وإدارة أثر القرارات الهندسية. تعتمد هوية بصرية بأخضر النخيل ودرجات الرمل والذهبي الهادئ.

## تشغيل محلي

افتح `index.html` في متصفح حديث، أو شغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## أقسام النموذج

- نظرة عامة للمكتب والمشاريع والتنبيهات.
- المشاريع، المهام، الملفات، الاعتمادات، والفريق.
- ترابط الطلبات والقرارات والملفات والمهام في خريطة تفاعلية.
- تحليل أثر توضيحي يعرض المصادر والمعلومات الناقصة.
- مقترح تصميم وخطة تنسيق يتطلبان اعتمادًا بشريًا.
- مساعد عربي تجريبي يجيب من سجلات العرض المحددة.

## حدود نسخة العرض

كل البيانات المعروضة تجريبية. لا يوجد تسجيل دخول حقيقي أو قاعدة بيانات أو رفع ملفات فعلي أو مزود AI متصل. لا تُستخدم مقترحات الذكاء الاصطناعي كاعتماد هندسي. قبل استخدام بيانات حقيقية، يجب ربط الواجهة بخلفية آمنة تضبط الصلاحيات والتخزين وسجل التدقيق.

بعد اكتمال مراجعة الواجهات، المرحلة التالية هي ربط وظائف الذكاء الاصطناعي بخلفية موحدة وآمنة، مع حفظ مفاتيح API كـ GitHub Secrets وعدم تضمينها في الواجهة.
