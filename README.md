# خلية | KHALIYA

منصة عمل للمكاتب الهندسية تربط المكتب ومديري المشاريع والموظفين والعملاء والاستشاريين بمساحات وصلاحيات خاصة بكل دور.

## التطبيق

- واجهات عربية وإنجليزية متجاوبة، مع إعدادات المظهر وحجم الخط.
- Firebase Authentication لحسابات المستخدمين، وCloud Firestore لبيانات المكتب والمشاريع والمهام والطلبات والاجتماعات والملفات.
- معرّف حساب فريد بصيغة `KHL-<Firebase UID>`، ودعوات تربط الحسابات بالمكتب.
- مساعد KHALIYA AI يتصل بخدمة Worker الحالية للبحث والتحليل والملخصات. الملفات المرفوعة تمر بخدمة Worker لتحليلها وفهرستها.
- صفحات الموقع الثابتة تُنشر عبر GitHub Pages عند تحديث فرع `main`.

## تشغيل محلي

شغّل خادم ملفات ثابتًا من مجلد المشروع، ثم افتح `index.html`. فتح الصفحات عبر `file://` لا يدعم وحدات JavaScript.

## نشر قواعد Firestore

بعد مراجعة `firestore.rules`، سجّل الدخول إلى Firebase CLI بحساب لديه صلاحية على المشروع ثم نفّذ:

```sh
npx firebase-tools login
npx firebase-tools deploy --only firestore:rules
```

معرّف مشروع Firebase مضبوط في `.firebaserc`. لا تُنشر قواعد Firestore تلقائيًا من Pages.

## ملاحظات تشغيلية

- تفضيلات العرض فقط تُحفظ محليًا؛ بيانات المشاريع وطلبات المستخدمين تحفظ في Firestore.
- لا تستخدم بيانات أو ملفات سرية في بيئة غير معتمدة. صلاحيات Firestore هي الحد الفعلي للوصول.
- مخرجات الذكاء الاصطناعي دعم للمراجعة، ولا تعتمد قرارات أو مخططات هندسية للتنفيذ دون مراجعة المختص.
- اختبر قواعد Firestore عبر Firebase Emulator قبل تعديل الصلاحيات أو إطلاق قواعد جديدة.
